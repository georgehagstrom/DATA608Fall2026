# DATA 608 - Knowledge and Visual Analytics - Fall 2026

Course website for DATA 608 at the CUNY School of Professional Studies,
published at <https://georgehagstrom.github.io/DATA608Fall2026/>.

- `website/` — Quarto source for the site. Render with `quarto render` from
  inside `website/`.
- `docs/` — rendered site output (GitHub Pages serves from here).

The course content was migrated from the Spring 2025 Brightspace course export
(`D2LExport_*.zip`, kept locally and gitignored).
