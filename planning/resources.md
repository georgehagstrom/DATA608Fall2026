## Rougier book profile

**Nicolas P. Rougier, *Scientific Visualization: Python + Matplotlib* (2021).** Open-access; book text licensed **CC BY-NC-SA 4.0**, code BSD-2-Clause (see LICENSE.txt in repo).

Where to get it (verified):
- GitHub repo (sources, all code, up-to-date PDF): https://github.com/rougier/scientific-visualization-book
- Direct PDF (in-repo, 95 MB): https://raw.githubusercontent.com/rougier/scientific-visualization-book/master/pdf/book.pdf
- HAL open archive record (canonical citation; currently behind an anti-bot wall for scripts but fine in a browser): https://hal.inria.fr/hal-03427242

Structure (from repo `rst/main.rst`):
- **Part I – Fundamentals:** Anatomy of a figure; Coordinate systems; Scales & projections; Elements of typography; A primer on colors
- **Part II – Figure design:** Ten simple rules (for better figures); Mastering the defaults; Size, aspect & layout; Ornaments (legends, annotations, decoration)
- **Part III – Advanced concepts:** Animation; Going 3D; Optimization; Graphic library (beyond matplotlib)
- **Part IV – Showcase:** gallery of advanced worked examples
- Plus: Introduction, Conclusion, Cheatsheets, External resources

**Covers well:** matplotlib internals and figure anatomy; coordinate systems/transforms and projections; scales; typography in figures; color theory as applied in matplotlib; legends/annotations/ornaments; layout; animation; 3D rendering; performance optimization; polished scientific-figure craft ("ten simple rules" chapter is a genuinely good design-principles reading).

**Does NOT cover:** statistical chart grammar / ggplot-style layered graphics (it is imperative matplotlib, not grammar-of-graphics); data wrangling; chart-type selection theory (no "which chart for which question" taxonomy); perception research; storytelling/narrative; audience/communication strategy. It is a Python production-craft complement to Wilke/Healy, not a replacement for the Knaflic material.
